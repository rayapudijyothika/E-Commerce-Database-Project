

# E-Commerce Database Management System

## Project Overview
This project is developed using MySQL.
It manages users, products, categories,
orders, order items and payments.

## Technologies Used
- MySQL
- SQL
- MySQL Workbench
- Visual Studio Code
- Git and GitHub

## Database Tables
1. Users
2. Categories
3. Products
4. Orders
5. Order_Items
6. Payments

## Project Features
- Database and table creation
- Primary Keys and Foreign Keys
- Data insertion
- Joins and Subqueries
- Views
- Stored Procedures
- Functions
- Triggers
- Transactions
- COMMIT and ROLLBACK
